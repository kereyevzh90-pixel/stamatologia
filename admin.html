Публикация изменений
Нажми «Опубликовать» — изменения уйдут на сайт за 1–2 минуты
FAQ — точные ответы
Добавь вопросы и ответы. Когда клиент спрашивает похожее — ассистент использует твой ответ как приоритетный. После изменений нажми «Опубликовать» вверху.
Системный промпт
Главная инструкция для ИИ: кто он, как говорит, что знает. Оставь пустым — будет использован стандартный встроенный промпт. После изменений нажми «Опубликовать» вверху.
GitHub Token
Нужен один раз чтобы админка могла публиковать изменения на сайт.
Как получить: github.com/settings/tokens → выбери scope repo → Generate token. Вставь сюда.
